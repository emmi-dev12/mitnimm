# Contributing

mitnimm is a hobby map. Small, boring patches are welcome. Big rewrites of the product rules are not.

## Rules that do not move

- Switzerland only.
- You have to be on site, with the live camera, to post. No camera roll.
- Photo is the pile, not the house. No façade, no house number.
- No accounts, no comments, no money.

## How to run

```bash
npm install
npm run dev
```

Web: http://localhost:5173 — API: http://127.0.0.1:8787

Open a PR against `main`. Keep the zip-tie look (see `PRODUCT.md`). Don’t invent user counts or press quotes.
